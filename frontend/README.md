# SGTU - Módulo Frontend (Angular)

Este directorio está reservado para la aplicación cliente del **Sistema de Gestión de Tutorías Universitarias (SGTU)** desarrollada en Angular.

## Estado actual
- Directorio preparado para la inicialización e integración del proyecto Angular.
- El cliente web se comunicará con la API REST del backend (`http://localhost:8080/api`).

## Estructura esperada
Cuando se genere el proyecto Angular con el Angular CLI (`ng new frontend` o similar), los archivos del frontend residirán en este directorio.
